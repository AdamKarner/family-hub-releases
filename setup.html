Need help?

What if I only have a phone?

That's fine. Move between this guide, Firebase Console, and Family Hub using your phone's app switcher. You can return to the same step without starting over.

Why won't my email and password work?

Check that Email/Password sign-in is enabled, the user exists in your Firebase project, and you've imported that project's JSON file on this phone or tablet.

What if I get a permission error?

Check that Firestore rules were published and that the email used to generate the rules exactly matches the signed-in household account.

Can I use my Wall display?

The documented Wall build uses a built-in Firebase project and does not provide a JSON import picker. Confirm compatibility before expecting it to join your family's private Firebase project.

Is this free?

Firebase offers a free Spark plan with usage limits. The documented Family Hub household setup does not require paid Firebase services. You can monitor usage in the Firebase Console.
