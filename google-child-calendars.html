How to create a calendar for each child

Keep school, sports, appointments, and family plans organized in one Google account. Your kids don't need their own Gmail addresses.

What you'll set up

For example, one parent can manage calendars named Family, Emma, and Noah. Each can have its own events and color, while all can appear together on the same calendar screen.

You will need access to the Google account that will own the calendars. The creation steps work best in a computer browser.

1. Open Google Calendar on the web

  1. On a computer, visit calendar.google.com.
  2. Sign in with the parent or household Google account that will manage these calendars.
  3. On the left, next to Other calendars, select the + button.
  4. Select Create new calendar. If you don't see that option, open the Settings gear and find Add calendar → Create new calendar.

The Google Calendar phone apps can show and edit events on additional calendars, but creating a new calendar generally requires the website.

2. Create a child's calendar

  1. Enter a clear name such as Emma's Calendar.
  2. Optionally add a description such as “School, soccer, and appointments.”
  3. Check the time zone.
  4. Select Create calendar.
  5. Repeat for each child.

You now have separate calendars inside the same Google account—not separate Google accounts.

3. Give everyone a color

  1. Return to the main calendar view.
  2. Under My calendars, find the new calendar.
  3. Open its three-dot menu and choose a color.

For example, Emma could be purple, Noah blue, and shared family activities green. Other apps may show different colors.

4. Add events to the right calendar

  1. Select Create → Event.
  2. Enter the activity, date, and time.
  3. In the event details, select the calendar name (often your primary calendar by default).
  4. Choose the child's calendar and select Save.
Example

Emma — Soccer practice
Tuesday at 5:30 PM

5. See the whole family's schedule

On Google Calendar, use the checkboxes beside the calendar names under My calendars to show or hide each schedule. On a phone, open the Google Calendar app's menu and choose which calendars to display. If one is missing, confirm you're signed in to the right account and check the calendar's sync/visibility settings.

6. Share with another parent (optional)

  1. On the Google Calendar website, open Settings and select the child's calendar.
  2. Find Share with specific people or groups and add the other parent's Google account.
  3. Choose Make changes to events if they should help manage the schedule, or a viewing-only permission if they only need to see it.
  4. Send the invitation.
Keep children's information private

Don't make a child's calendar public. Calendar entries may reveal school names, locations, appointments, and daily routines. Share only with people who need access.

Google Family calendar vs. a child's calendar

If you use a Google family group, Google may already provide a shared Family calendar. That's useful for plans involving everyone. A separate calendar for each child is an additional calendar you create and control; it doesn't automatically become part of Google's family-group sharing or give the child access.

You can use both: the Family calendar for group activities, and each child's calendar for individual events.

Connect each child's calendar to Kindlane on Android

Before you start: you will need each calendar's secret iCal link

Kindlane Android currently requires the Secret address in iCal format for every Google calendar you want to connect. This is a private calendar URL, not your Google password or an API key. Copy a different link for each child's calendar, then paste it into Kindlane when adding that calendar. Normally you do this once per calendar; if you disconnect it or reset its secret address in Google, you must enter the current link again. Never publish or send these links in a group chat: anyone with a link may be able to read that calendar's events.

Kindlane's Android app uses a private Google iCal link for each calendar. It matches a calendar to a person when the calendar name includes that person's name.

  1. Add the person: In Kindlane, open People and photos and add your child, such as Emma, if needed.
  2. Copy the private calendar link: On the Google Calendar website, open Settings, select the child's calendar under Settings for my calendars, then find Integrate calendar → Secret address in iCal format. Copy this link. Some Google accounts restrict access to secret links.
  3. Connect it in Kindlane: In the Android Calendar tab, open calendar management. Enter a name such as Emma's Calendar, paste Emma's secret iCal link, and tap Add calendar. Repeat for each child. A configured Settings PIN may be required.
  4. Check the match: Open the Kindlane calendar. Emma's events should use Emma's photo or initial when the names match. If the Kindlane person is named Emma, a calendar named Emma's Calendar matches; an unrelated name does not.
  5. Choose the device view: Open Settings → This device and select Emma's profile. Kindlane initially selects calendars matching her name. Adjust Calendars shown if needed. This choice is saved on the current device only.
Privacy note

Calendar visibility and device profiles are display preferences, not household security permissions. Only connect calendars appropriate for people using those devices. Keep secret iCal links private: anyone who has one may be able to read the events.

Kindlane web works differently

On the web, open Add or import calendar events to import an exported Google Calendar .ics file. This creates a snapshot rather than a live subscription, and does not associate the imported calendar with an individual child's profile. The Android secret-link and name-matching instructions above do not apply to web.

Troubleshooting

Confirm you used the correct calendar's secret link, the Kindlane calendar name includes the child's name in People and photos, and the calendar is checked under Settings → This device → Calendars shown. Refresh the calendar; Google subscription updates may not be immediate.

Frequently asked questions

Does each child need a Gmail address?

No. A parent can own multiple calendars in one Google account.

Can both parents add events?

Yes, if the calendar owner shares it with the other parent and grants editing permission.

Can I create the calendars from my phone?

The mobile apps generally don't offer new-calendar creation. Use the Google Calendar website on a computer, or try your mobile browser's desktop-site option.

Can I move an event to another calendar?

Usually, yes, for events and calendars you can edit. Some invitations or event types have restrictions.

Will deleting a calendar remove its events?

Deleting a secondary calendar can permanently remove its events. Hide the calendar instead if you only want to stop seeing it.

Do I need Google's Family calendar?

No. Individual calendars work without a Google family group.
