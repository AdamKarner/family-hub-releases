Common questions

Does Firebase cost money?

Firebase has a no-cost Spark plan with usage limits. For a small household, this is often enough, but usage and eligibility are not guaranteed. Review Firebase pricing before enabling paid services.

What if the sync dot is red?

Check that Firestore was created, the published rules use the exact email you signed in with, and the right Firebase project was imported. Tap the sync status in Family Hub for the specific error.

Do I need to upload my Firebase file anywhere online?

No. Download it from Firebase and import it directly into Family Hub on your device. Never paste your family's sign-in password into a setup website. Don't publish the file in a public repository.

Will a wall display automatically use my private Firebase project?

Not with the current documented Wall build. Its built-in Firebase configuration is separate from a private project imported on a phone. Check which project each device is using before expecting them to synchronize.

Can I add another phone or tablet later?

Yes. For a private Firebase project, import the same google-services.json on each additional phone or tablet, restart, then sign in with your household account.
