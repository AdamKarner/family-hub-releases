Getting started

Get your household connected.

Start a household, join your family with an invitation, or keep using your existing setup safely.

Already using Family Hub? Do not create a second household, clear app data or uninstall your working copy to troubleshoot. Confirm your existing data first.
New household

Create your household

  1. Install Family Hub for Android.
  2. Open Settings → Sync across devices → Household.
  3. Sign in with Google, then choose Create household.
  4. From Members, choose Invite a grown up or Invite a kid and share the one-time code privately.
  5. Assign children's Daily lists and review their Permissions.
  6. Verify an item syncs across two devices.
Invited family member

Join your family

  1. Install the Android app and open Settings → Sync across devices → Household.
  2. Sign in with your own Google account.
  3. Choose Join with a code and enter the owner's invitation.
  4. Codes work once and expire; request another code if needed.
  5. Confirm you can see your household's expected information.
Existing older configuration

Preserve your family data

Families using an older shared login or their own Firebase project should keep that configuration until a verified migration. Avoid testing migration on actual household data.

We've retained the illustrated manual setup and connection guide for these families.

Other devices

Connect the right device

The Android and Wall downloads are different. Wall devices without Google can use supported email sign-in. Confirm household compatibility before pairing a wall.

iPhones cannot install Android APKs. A separate browser-based Family Hub experience exists; access and feature coverage can differ.

Device installation guide

Check that syncing works

Signing in or seeing a connection indicator isn't a complete sync test. Add a harmless temporary item on one device, confirm it appears on a second connected device, and remove it. Test migration and kid permissions in a separate test household.
